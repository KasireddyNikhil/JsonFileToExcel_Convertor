**🚀 Project Overview**

The REX Application is a document management system designed for structured content creation, review, and approval. It enables users to submit, edit, approve, and delete content while maintaining role-based access control.

This system is built with Python (Tkinter) & SQLite, offering an interactive UI with advanced text formatting, search functionality, and notification management.


**📌 Key Features**

✅ Role-Based Access: Admins can approve or reject edits & deletion requests.
✅ Dynamic UI: Supports bold, italics, underline, hyperlinks, and bullet points.
✅ Search Functionality: Users can search and highlight content dynamically.
✅ Real-Time Notifications: Users receive alerts on content approval, rejection, and changes.
✅ Database Integrity: Uses SQLite with WAL mode & locking mechanisms for secure concurrent access.
✅ Approval Workflow: Content goes through an approval pipeline before being published.

**🔧 Tech Stack**

Frontend: Tkinter (Python GUI)

Backend: SQLite (Database)

Concurrency Handling: File locking & WAL Mode

Version Control: Git & GitHub
